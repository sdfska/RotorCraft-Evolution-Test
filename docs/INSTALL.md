# RotorCraft Evolution, test build 90fa7092

Flyable helicopters for DayZ 1.30: Mosquito, MH-6, Gazelle, Black Hawk and an open-cabin Black Hawk.

## Players

1. Download `RotorCraftEvolution-90fa7092.zip` and unzip it. You should get one folder, `@RotorCraftEvolution`, with `addons`, `keys`, `mod.cpp` and `release` inside. If an older `@FlyProto` folder is still around, delete it; it is not used any more.
2. Subscribe to **Community Framework** and **VPP Admin Tools** on the Steam Workshop. The test server loads both.
3. In the DayZ Launcher, open **Mods**, choose **Local mod**, and add the `@RotorCraftEvolution` folder. Tick it together with Community Framework and VPP Admin Tools.
4. Join the server with the address and password the host gives you.

If the server refuses you with a signature or version message, the unzip was incomplete or an old mod folder is still loaded. Unzip again into an empty folder and check that `addons\RotorCraftEvolution.pbo` is about 49 MB.

Controls are in `release\KEYBINDINGS.md` inside the mod folder, and `release\PLAYER_GUIDE.md` covers starting up, fuel, repairs and landing. Wind affects every aircraft; the big ones drift most.

## Known issues in this build

- From a passenger seat, or when watching someone else's helicopter, turns look stepped. The pilot's own view is smooth. This is being worked on.
- The Black Hawk co-pilot seat sits too far forward.

## Server hosts

`ADMIN_GUIDE.md` and `RotorCraftEvolution-server-files.zip` cover the server side: mod line, key, spawn files and the settings written to the profile folder on first start.
